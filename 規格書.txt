# 心智圖專案規格書

## 1. 專案簡介
本專案是一個基於 Django 框架的心智圖應用，前端使用 jsMind 來可視化心智圖的操作。目的是為用戶提供一個可以創建、保存、管理心智圖的工具，並且支援多用戶的數據隔離，確保每個用戶擁有自己的專屬心智圖。

## 2. 系統架構
- **後端框架**：Django
- **前端框架**：jsMind, JavaScript, HTML, CSS
- **數據庫**：SQLite（開發階段），可切換至 PostgreSQL 等其他數據庫進行部署

## 3. 功能概述

### 3.1 用戶功能
- **註冊與登入**：用戶可以進行帳號註冊與登入，並且通過 Django 的身份驗證系統來管理登入狀態。
- **個人心智圖管理**：每個用戶都有專屬的心智圖數據，登入後可以創建、編輯和保存心智圖。
- **心智圖數據儲存與讀取**：支援用戶保存心智圖的數據，並在頁面加載時自動讀取用戶的心智圖。

### 3.2 心智圖功能
- **創建節點和子節點**：用戶可以在心智圖上添加節點或子節點，隨時擴展心智圖結構。
- **節點編輯**：支援對節點內容進行編輯、修改、刪除。
- **拖拽節點**：用戶可以使用鼠標拖拽節點以調整節點的位置，類似於 Google Map 的拖拽操作。
- **保存和載入**：用戶可以保存當前心智圖狀態，當重新登入或刷新頁面時自動加載已保存的心智圖。

## 4. 技術詳情

### 4.1 Django 模型
- **User**：使用 Django 內建的用戶模型來管理用戶信息。
- **MindMap**：一對一關聯 `User`，包含以下欄位：
  - `user`：與 `User` 的一對一外鍵。
  - `title`：心智圖的標題。
  - `data`：JSON 格式的心智圖數據。
  - `created_at` 和 `updated_at`：自動追蹤心智圖的創建與更新時間。

### 4.2 視圖和 API
- **保存心智圖** (`save_mindmap`)：處理 `POST` 請求，保存用戶的心智圖數據至數據庫。
- **加載心智圖** (`load_mindmap`)：處理 `GET` 請求，從數據庫讀取當前用戶的心智圖數據。

### 4.3 前端交互
- **jsMind 集成**：使用 jsMind 來渲染和管理心智圖的前端操作。通過 AJAX 與 Django API 交互以保存和加載數據。
- **登入與驗證**：在前端通過 JavaScript 驗證用戶是否登入，控制不同的交互元素顯示。

## 5. 數據流程
1. **用戶登入**：用戶透過 Django 的登入接口登入系統。
2. **心智圖加載**：登入成功後，前端發送 `GET` 請求至 `/api/load_mindmap/`，獲取用戶的心智圖數據，並使用 jsMind 渲染。
3. **心智圖操作**：用戶可以在前端進行各種操作（如新增、編輯節點），完成後可以選擇保存。
4. **心智圖保存**：當用戶點擊保存按鈕時，前端發送 `POST` 請求至 `/api/save_mindmap/`，後端更新數據庫中的心智圖。

## 6. 測試計劃
- **未登入用戶測試**：嘗試訪問心智圖的保存與加載 API，預期返回 401 未授權。
- **新用戶登入測試**：新用戶首次登入應返回空心智圖數據。
- **數據隔離測試**：不同用戶登入後，應各自管理自己的心智圖數據，無法訪問其他用戶的數據。
- **API 功能測試**：測試心智圖的保存與加載 API 是否正常工作。

## 7. 安全考慮
- **身份驗證與授權**：使用 Django 內建的登入系統，通過 `@login_required` 裝飾器確保只有登入用戶才能存取心智圖。
- **CSRF 保護**：對所有涉及數據修改的 API 都加上 CSRF 保護，防止跨站請求偽造攻擊。
- **數據隔離**：確保所有心智圖操作都是基於當前登入用戶進行，避免不同用戶之間的數據混淆。

## 8. 未來擴展計劃
- **心智圖分享**：允許用戶將自己的心智圖分享給其他用戶或生成分享鏈接。
- **版本控制**：增加版本控制功能，允許用戶回溯到以前保存的心智圖版本。
- **多平臺支持**：考慮增加移動設備的支援，讓用戶可以在手機或平板上管理心智圖。

## 9. 開發指南
- **開發環境**：推薦使用 `Python 3.x` 和 Django 最新版，前端使用 `jsMind`，以及 `JavaScript`、`HTML`、`CSS`。
- **安裝依賴**：使用 `pip` 安裝依賴包，例如 `pip install django`。
- **數據庫遷移**：運行 `python manage.py makemigrations` 和 `python manage.py migrate` 以創建和更新數據庫。
- **測試執行**：運行 `python manage.py test` 來執行測試並確保系統的各項功能正常。
